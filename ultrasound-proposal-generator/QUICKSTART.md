# 🚀 Quick Start Guide

## Fastest Way to Generate Your Proposal (30 seconds)

### Method 1: Browser (Recommended - No Setup Required)

1. **Open the file:**
   - Double-click `index.html`
   - Or right-click → Open with → Your Browser

2. **Generate PDF:**
   - Click the blue "📥 Download PDF" button
   - Your proposal will download instantly

3. **Done!**
   - Find `Ultrasound_Sales_Proposal.pdf` in your Downloads folder

### Method 2: Node.js (For Developers)

```bash
# 1. Install dependencies (first time only)
npm install

# 2. Generate PDF
npm run generate

# 3. Find your PDF in the output/ folder
```

## What You Get

A professional 3-4 page PDF proposal including:
- ✅ System specifications (Philips iU22 xMATRIX)
- ✅ 4 Probe details (C5-1, V6-2, L17-5, 3D9-3V)
- ✅ Complete pricing breakdown (₹10,08,900 total)

- ✅ 30+ key features
- ✅ Payment & delivery terms
- ✅ Professional formatting

## Customize Before Generating

**Edit `proposal-template.json` to change:**

- Client name and details
- Pricing and discounts
- Contact information
- Dates and reference numbers
- Equipment configuration

**Common Changes:**

```json
// Change client name (line ~35)
"[Hospital / Radiology Dept]" → "ABC Hospital"

// Change price (line ~70)
"9,50,000" → "10,00,000"

// Change contact (line ~25)
"+91-XXXXX-XXXXX" → "+91-12345-67890"
```

## Preview Before Download

Click "👁️ Preview in Browser" to see the PDF before saving.

## Need Help?

1. Check the full [README.md](README.md) for detailed instructions
2. View the template: Click "📝 View Template JSON"
3. Browser console: Press F12 to see any error messages

## Tips

- **Best Browser:** Chrome or Edge (best PDF support)
- **File Size:** Generated PDF is ~50KB (very small, easy to email)
- **Offline:** Works without internet connection
- **Security:** All processing happens locally on your computer
