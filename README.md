# Neuro Assessment System v2.1

A comprehensive web-based neurological diagnostic platform designed for healthcare professionals to perform systematic assessments of various neurological conditions.

## 🧠 Overview

The Neuro Assessment System is an advanced diagnostic tool that provides structured assessment modules for major neurological conditions. It features multilingual support (Tamil/English), evidence-based scoring algorithms, and comprehensive reporting capabilities.

## ✨ Features

### Diagnostic Modules
- **🔍 Functional Neurological Disorder (FND)** - Comprehensive assessment with functional signs evaluation
- **⚡ Epilepsy/Seizure Disorders** - ILAE classification system with EEG analysis protocols
- **🧬 Multiple Sclerosis** - McDonald criteria implementation with MRI and CSF evaluation
- **🤝 Parkinson's Disease** - UPDRS scoring system with motor assessment and levodopa response
- **🚨 Stroke/CVD Emergency** - NIHSS calculator with time-critical treatment protocols

### Key Capabilities
- **Patient Registration System** - Comprehensive patient data management
- **Tamil Voice Input** - Native language support for patient interviews
- **Evidence-Based Scoring** - Validated assessment algorithms
- **Print Reports** - Professional diagnostic reports generation
- **Responsive Design** - Works on desktop, tablet, and mobile devices

## 🚀 Quick Start

1. Open `neuro_assessment_system.html` in a modern web browser
2. Register a new patient using the Patient Registration tab
3. Select the appropriate diagnostic module
4. Complete the assessment forms
5. Generate and print the diagnostic report

## 🔧 System Requirements

- Modern web browser with JavaScript enabled
- For voice input: Browser with Web Speech API support (Chrome, Edge)
- Internet connection not required (runs offline)

## 🏥 Clinical Applications

This system is designed for use by:
- Neurologists
- Emergency physicians
- General practitioners
- Medical students and residents
- Healthcare facilities requiring systematic neurological assessments

## 📊 Assessment Scoring

Each module uses validated clinical criteria:
- **FND**: Confidence scoring based on functional signs and investigations
- **Parkinson's**: UPDRS-based likelihood assessment
- **Stroke**: NIHSS scoring with treatment window calculations
- **MS**: McDonald criteria implementation
- **Epilepsy**: ILAE classification system

## 🔒 Privacy & Security

- All data is processed locally in the browser
- No patient information is transmitted over the internet
- Suitable for use in secure healthcare environments
